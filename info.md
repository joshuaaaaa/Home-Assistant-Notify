# Notify Card

Custom Lovelace card pro odesílání notifikací v Home Assistant.

## Funkce

- 📱 Výběr notifikačního nástroje (mobil, Telegram, atd.)
- ✉️ Pole pro napsání zprávy
- 🚀 Jednoduché odesílání kliknutím
- 🔍 Automatická detekce všech dostupných notify služeb

## Použití

Přidejte kartu do Lovelace pomocí UI nebo YAML:

```yaml
type: custom:notify-card
title: Odeslat notifikaci
```
